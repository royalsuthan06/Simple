### 1. JDBC Database Connection (Lab Simulation)

```java
import java.util.Scanner;

public class JDBCDemo {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.println("Connecting to Database: jdbc:mysql://localhost:3306/collegedb");
        System.out.println("Connected to Database successfully!\n");

        System.out.print("Enter Student Roll No: ");
        int roll = sc.nextInt();
        sc.nextLine();
        System.out.print("Enter Student Name: ");
        String name = sc.nextLine();

        System.out.println("\nQuery OK, 1 row affected.");
        System.out.println("\n--- Student Records ---");
        System.out.println("RollNo: " + roll + " | Name: " + name);
        System.out.println("Database connection closed.");
        sc.close();
    }
}

```

**Expected Output:**

```text
Connecting to Database: jdbc:mysql://localhost:3306/collegedb
Connected to Database successfully!

Enter Student Roll No: 101
Enter Student Name: Alex

Query OK, 1 row affected.

--- Student Records ---
RollNo: 101 | Name: Alex
Database connection closed.

```

### 8. Applet with Factorial ("Compute")

```java
import java.applet.Applet;
import java.awt.*;
import java.awt.event.*;

/* <applet code="FactApplet.class" width="250" height="150"></applet> */

public class FactApplet extends Applet implements ActionListener {
    TextField t = new TextField(5);
    Button b = new Button("Compute");
    int fact = 1;

    public void init() {
        add(t);
        add(b);
        b.addActionListener(this);
    }

    public void actionPerformed(ActionEvent e) {
        int n = Integer.parseInt(t.getText());
        fact = 1;
        for (int i = 1; i <= n; i++) fact *= i;
        repaint();
    }

    public void paint(Graphics g) {
        g.drawString("Factorial: " + fact, 20, 80);
    }
}

```

**Expected Output:**

*(Enter `5`, click `Compute`)*

```text
Factorial: 120

```

### 15. Hybrid Interface

*(Extending one class while implementing multiple interfaces, or one interface extending another along with a common class)*

```java
interface Walkable {
    void walk();
}

interface Runnable {
    void run();
}

class LivingBeing {
    void breathe() {
        System.out.println("Breathing...");
    }
}

public class HybridDemo extends LivingBeing implements Walkable, Runnable {
    public void walk() { System.out.println("Walking..."); }
    public void run()  { System.out.println("Running..."); }

    public static void main(String[] args) {
        HybridDemo h = new HybridDemo();
        h.breathe();
        h.walk();
        h.run();
    }
}

```

**Expected Output:**

```text
Breathing...
Walking...
Running...

```
